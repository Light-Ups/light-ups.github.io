An ESP32-based bridge that makes any USB UPS network-aware — no cloud, no subscription.

Network your UPS

Connects to your UPS via USB and broadcasts telemetry over Ethernet to up to 4 PCs simultaneously. When power fails, every connected PC shuts down safely. Ideal for small offices and server rooms where multiple machines share one UPS.

mDNS: lightups.local SSDP: Windows Discovery
🖥

Web Dashboard

Open http://lightups.local in any browser — or find the device in Windows Network via SSDP. No app to install. Configuration is straightforward: claim a slot, copy the token, and enter it in the LightUps settings.

  • Dashboard: manage up to 4 PC client slots, view and claim connections, copy authentication tokens
  • Settings: change hostname, IP (DHCP/static), TLS port, admin password
  • Auto-reboot: network changes trigger a graceful reboot with countdown
🔐

End-to-end Encryption

All telemetry is sent over TLS 1.2 with PSK ciphers. Each PC gets a unique authentication token. ARP-based fraud detection prevents MAC spoofing.

How to connect a PC

Open the Satellite web dashboard, claim an available slot, and copy the token. Enter the hostname or IP address, the MAC address, and the token in the TLS PSK Ethernet Driver settings of the LightUps service.
